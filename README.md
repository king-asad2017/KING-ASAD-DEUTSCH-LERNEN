# 👑 KING ASAD – مرکز آموزش زبان آلمانی

اپلیکیشن تحت وب و پیشرونده (**PWA**) برای یادگیری زبان آلمانی از سطح **A1 تا C1** شامل **۱۲۹ درس**، تلفظ دوزبانه آلمانی و فارسی، فرهنگ لغت و ترجمه، ویدیوهای آموزشی و آزمون‌های سطح‌بندی.

## ✨ امکانات برنامه
* **۱۲۹ درس جامع:** تقسیم‌بندی‌شده در سطوح `A1`، `A2`، `B1`، `B2` و `C1` همراه با مکالمه، واژگان و نکته گرامری.
* **تلفظ صوتی آلمانی و فارسی:** امکان شنیدن تلفظ واژه‌ها و جمله‌ها به هر دو زبان.
* **فرهنگ لغت و ترجمه:** جستجو و ترجمه بین زبان آلمانی و فارسی.
* **ویدیو و آزمون:** منابع ویدیویی تفکیک‌شده برای هر سطح و آزمون‌های تعاملی با ثبت امتیاز.
* **قابلیت نصب (PWA):** قابل نصب روی صفحه اصلی گوشی و آماده تبدیل به بسته اندروید (`.aab`) برای انتشار در Google Play.

## 🌐 لینک نمایش سایت
`https://نام-کاربری.github.io/نام-ریپازیتوری/`

## 🛠️ فایل‌های پروژه
* `index.html` — رابط کاربری، درس‌ها، فرهنگ لغت، ویدیوها و آزمون‌ها
* `manifest.json` — تنظیمات نصب اپلیکیشن روی دستگاه‌ها
* `sw.js` — سرویس ورکر برای مدیریت کش و عملکرد روان‌تر
